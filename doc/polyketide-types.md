# Three types of polyketide synthases

Polyketides are natural products built from small carbon building blocks. The labels **Type I, Type II, and Type III** usually describe the **polyketide synthase (PKS) enzymes** that make them, rather than three strict categories of the products themselves.

| Feature | Type I PKS | Type II PKS | Type III PKS |
|---|---|---|---|
| Organization | Large proteins containing multiple functional domains | Several separate, specialized proteins working together | One kind of enzyme, usually functioning as a pair of identical copies |
| How the chain is built | Domains within large proteins cooperate to extend and modify the chain | Separate proteins cooperate to extend the chain, often producing an aromatic backbone | The enzyme extends and cyclizes the chain within its active site |
| Acyl carrier protein (ACP) | Uses an ACP domain, usually built into the large protein | Uses a separate ACP protein | Does not use ACP; accepts building blocks from CoA-linked substrates |
| Example product | Erythromycin | Tetracycline | Plant chalcones |
| Simple analogy | An assembly line with several workstations built into large machines | A team using separate specialized tools | A compact machine doing several steps itself |

## Type I: large proteins with multiple domains

Each domain is a section of a protein that performs a particular task, such as adding a building block or modifying the growing chain. Some Type I systems use several large proteins together.

Many Type I PKSs are **modular**: successive modules perform successive rounds of chain extension. Others are **iterative**: the same domains are reused for multiple rounds.

## Type II: a team of separate proteins

Type II PKSs distribute their tasks among separate proteins. An **acyl carrier protein (ACP)** holds the growing chain and presents it to the other enzymes. These systems commonly make aromatic polyketides.

## Type III: chain building without ACP

Type III PKSs are relatively compact enzymes, usually made of two identical protein subunits. They use CoA-linked substrates and hold the growing chain in their active site, without an ACP. A familiar example is **chalcone synthase**, which helps plants make precursors of flavonoids.

### Is this like building a polymer?

Yes, in the sense that **the enzyme repeatedly adds small building blocks to a growing chain**. However, Type III PKSs usually perform only a few extension steps and often cyclize the resulting chain to form a ring, producing a relatively small molecule rather than a long polymer. Repeated chain extension also occurs in Types I and II; it is not unique to Type III.

For example, **chalcone synthase** combines one starter unit (p-coumaroyl-CoA) with three extender units (malonyl-CoA), then forms a ring to produce a chalcone. Carbon dioxide is released during each extension step.

## Main takeaway

- **Type I:** multiple working domains combined in large proteins.
- **Type II:** separate specialized proteins working together with ACP.
- **Type III:** a compact enzyme performs the core chain-building steps without ACP.

Protein size alone does not define the type. **Organization and use of ACP are the more useful distinctions.**
